memuat…

Mode server-side · 10.000 baris di server

Pagination, sort, filter, dan pencarian diproses di GET api/halaman (server.mjs) — grid hanya menerima satu halaman · lewat file:// fallback ke simulasi server-side lokal · navigasi keyboard: Tab ke tabel, panah pindah sel, Spasi pilih, Enter edit

Pakai

MiniGrid({
  el: '#grid',
  columns: [
    { name:'id',    label:'ID',     width:70,  type:'num' },
    { name:'nama',  label:'Nama',   width:180 },
    { name:'gaji',  label:'Gaji',   type:'num',
      format:'money', align:'right' },
    { name:'tgl',   label:'Masuk',  type:'date' },
    { name:'ok',    label:'Aktif',
      render: v => v ? '✓' : '✗' },
  ],
  data: rows,          // array objek biasa
  frozen: 2,           // 2 kolom kiri beku
  edit: true, add: true, remove: true,
  pageSize: 25, height: 420,
  crud: true,          // tombol + Tambah/Edit/Detail/Hapus (form modal)
  onSave: (row, isNew) => save(row),  // persist: localStorage/API
});
/* ---- petunjuk pakai dengan API ---- */
// 1) muat semua baris sekali (spt demo 5)
const g = MiniGrid({ el:'#grid', columns: cols, data: [] });
g.setLoading(true);                       // overlay "Memuat…"
fetch('api/karyawan').then(r => r.json())
  .then(rows => { g.data = rows; g.render(); })
  .finally(() => g.setLoading(false));

// 2) server-side: paging/sort/filter diproses server (spt demo 6)
MiniGrid({
  el:'#grid', columns: cols, data: [],
  server: p => fetch('api/halaman?' + new URLSearchParams({
    page: p.page, size: p.size, q: p.q,
    sort: JSON.stringify(p.sort),         // [[kolom, 1|-1], …]
    filters: JSON.stringify(p.filters),   // { kolom: {op, q} }
    rules: JSON.stringify(p.rules),       // builder kondisi AND/OR
    join: p.join,
  })).then(r => r.json()),  // wajib balas { rows, total }
  onRefresh: g => g.render(),             // tombol Refresh = muat ulang
});

Opsi

columns[]
name, label, width, type (str|num|date), format, align, render(), sortable, filter, editable, hidden, search
data
array objek — client-side. Ganti grid.data lalu grid.render().
select
'multi' (checkbox) | 'single' | false · selectAll: 'page' (default, ala jqGrid) | 'view' · bila false, tombol berbasis seleksi (Edit/Detail/Hapus) disembunyikan
filter/search
baris filter beroperator (= ≠ ∋ ^ $ > ≥ < ≤ ada kosong) + pencarian global · tombol Filter = filter cepat + builder kondisi lanjutan: field dipilih, kondisi dapat ditambah (satu field boleh lebih dari satu, mis. no > 10 dan no ≤ 20), digabung AND/OR, badge jumlah kondisi aktif
frozen
jumlah kolom beku di kiri (sticky)
crud
pintasan untuk tombol + Tambah · Edit · Detail · Hapus berbasis formulir modal (navGrid ala jqGrid); atau satuan: add / editForm / view / remove, edit = edit inline via klik ganda
actions
tombol kustom berikon: {id,label,icon,need:'one'|'some',fn(rows,grid)} — mis. Approve/Reject
filterForm/help
tombol Filter = semua filter kolom dalam satu form · tombol Help = modal panduan (teks bisa diganti via helpText)
server
fn(params)→Promise{rows,total} = mode server-side: sort/filter/paging di server, grid hanya merender satu halaman
detail
fungsi(row) penghasil HTML → master-detail: chevron di tepi kiri membentang baris detail (virtual scroll tetap akurat)
refresh
true (default) = tombol Refresh di toolbar; onRefresh(grid) diisi untuk memuat ulang data — bila mengembalikan Promise, overlay "Memuat…" tampil otomatis
rowActions
true = ikon Detail/Edit/Hapus per baris (tanpa perlu checkbox/seleksi)
formCols
jumlah kolom layout formulir Tambah/Edit (1, 2, atau 3)
tema
pemilih tema di kepala halaman (Terang, Gelap, Samudra, Hutan, Senja, Monokrom), tersimpan di localStorage; implementasi = remap variabel warna Tailwind v4 via [data-theme]
Export
menu CSV / XLSX / PDF — writer asli tanpa library, mengikuti hasil ter-filter & ter-urut
kolom: form
options:[…] jadi select · required validasi wajib · bool jadi checkbox · form:false sembunyikan dari formulir · editable:false blok edit
tinggi
height, rowHeight, pageSize, pageSizes, zebra, resize, chooser, rowId()
metode
render() · refresh() · sortBy(n, tambah) · selected() · clearSel() · toCSV()
callback
onSave(row,isNew) · onEdit(row,col,val,old) · onAdd(blank) · onRemove(rows) · onSelect(ids) — tempat menyimpan ke localStorage/API

Operator filter per tipe kolom

Teks: = ≠ ∋(mengandung) ^(awalan) $(akhiran). Angka & tanggal: = ≠ > ≥ < ≤. Semua kolom: ada / kosong. Nilai tanggal ditulis 2024-01-31 atau 2024.

Build ulang CSS (butuh internet sekali)

npm i -D @tailwindcss/cli
npx tailwindcss -i ./src/input.css -o ./dist/tailwind.css --minify
node build.mjs        # inline CSS + JS ke dalam index.html → hasil akhir 1 file

Hasil index.html bisa dibuka dengan file:// atau ditaruh di USB/intranet tanpa server dan tanpa koneksi.
